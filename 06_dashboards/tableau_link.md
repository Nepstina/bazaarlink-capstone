# Tableau Public dashboard

**Link:** https://public.tableau.com/app/profile/nepstina.s/viz/bazaarlink_tableau_public/Dashboard

Data: `06_dashboards/data/tableau_orders.csv` (export of the MySQL view `vw_order_delivery` with state names and regions).
Sheets: Late rate map, Category view, Delay vs review, On-time trend. Filter action: select a state on the map to filter the other sheets.
